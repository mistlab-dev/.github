# MistLab

Building tools for teams that live in terminals and docs.

**Website:** [mistlab.dev](https://mistlab.dev)

## Products

### [MistTerm](https://github.com/mistlab-dev/MistTerm)
Free team SSH terminal — short-lived certificates, command audit, shared commands, and AI batch ops. Built with Rust and a GPU UI.

- [Download](https://mistlab.dev/#download) · [Docs](https://mistlab.dev/docs.html) · [Releases](https://github.com/mistlab-dev/MistTerm/releases)

### [MistDocs](https://github.com/mistlab-dev/mist-docs)
Collaborative team documentation — real-time editing, permissions, search, and share links.
